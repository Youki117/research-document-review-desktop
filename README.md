# 研发文档审查 · 下沙

Windows 桌面工具。提交 DOCX 或文本型 PDF，AI 审查后在正文中逐处修改确认，直接导出可使用的修正文档。v0.5.1；完整解压后双击“研发文档审查-下沙.exe”。不打开外部浏览器，无需另装 Python、Node.js 或办公编辑器。

## 正常使用

1. 通过“工具 → 模型设置”填写完整 Chat Completions 地址、模型名称和密钥。文档会发送到此接口；软件不包含离线模型。
2. 左栏添加文件或文件夹，点击“加入审查队列”。右栏选择文件，完成后自动定位首个待确认项。
3. 在标注旁的输入框内编辑文字，点击勾或按 Enter 确认，自动定位下一处。填回原文并确认即可保留原文。按 Esc 或点击框外收起，点击标注可再次打开。修改自动保存；中途退出后再打开文件，从下一处待确认项继续。
4. 全部确认后点击“导出修正文档”，得到“原文件名_已修正.docx”。人工决定直接应用到正文，移除本轮 AI 修订和批注，保留原文件格式。原件和机器标注副本不覆盖。导出后仍可继续修改并再次导出；旧导出文件保留。

仍有待确认项时，导出会提示数量并定位过去。保存失败会明确提示，不会显示为已保存；切换文件先保存，关闭时保护未保存内容。确认过的标注仍可点击重新编辑。“更多”保留下载标注版、报告和重新载入记录，供需要时核查。

失败或中断文件在中栏显示原因与“重试”。重试创建独立任务，保留原记录；核对原件、分块、接口与提示词后复用成功检查和相同候选的复核。扫描 PDF 需要先 OCR，已有修订的 DOCX 需要先在 Word/WPS 处理；单纯重试不能补出扫描文字。

## 文件与预览

每批最多 200 份，单文件最多 50 MiB。文件夹包含子目录；其他格式、Office 临时文件与重复项列入跳过清单。同名文件保留相对路径。

预览保留正文顺序、主要字体和段落样式、缩进、表格及常见图片，修改框浮在具体标注附近，不压缩正文。复杂域、公式、页眉页脚与精确分页仍以导出的 DOCX 为准，不等同完整办公排版引擎。PDF 支持文字预览及下载批注版，直接修改和修正文档导出目前支持 DOCX。

“AI审查完成”表示 AI 处理结束。建议仍需人工确认；无法安全定位或校验拒绝的建议保存在报告，不能把状态文案视为所有内容均正确或均已写入。

## 保存和升级

模型配置保存在 EXE 同目录“模型配置.json”，任务、原件副本与结果保存在 data/。请将整个文件夹放在可写目录。一个目录只允许一个窗口运行。退出时未完成任务会中断，重启后保留记录，可手动重试。

本地修改日志按月追加在 `data/修改记录-YYYY-MM.jsonl`，每行是一条 JSON 记录，含时间、任务 ID 和文件名。记录提交、开始、完成、失败、中断、重试关联，AI 已写入建议及未定位或被保护拒绝的建议，以及每次保存的人工修改前后文本、原文、AI 建议、理由、段落上下文、确认或保留原文的决定、修正文档导出。首次保存记录完整的建议基线；后续追加变更，不因重新编辑而覆盖历史。未保存的逐键输入不计作独立事件，旧版本的操作历史无法补录。日志失败会提示，已保存的正文决定仍保留。

日志包含文档片段和人工修改，仅保存在本机，不自动上传 GitHub，也不自动训练模型或改变审查规则。后续可按问题、改法和人工采用情况统计频次，再把证据充分的固定错误提炼为代码规则。升级复制整个 data/ 即可同时保留任务与日志。

每次启动后台检查 [GitHub Releases](https://github.com/Youki117/research-document-review-desktop/releases/latest)。有正式新版时提示“下载新版”，打开该仓库的发布页；离线或检查失败不影响使用。升级时退出旧版，解压新版本，将原 data/ 和模型配置复制到新目录，再启动新版。

公开仓库提供运行和构建所需的核心内容；分发 ZIP 配置为空，不含用户材料、任务历史或测试。下载更新不自动覆盖正在使用的程序和数据。

## 检查机制

按原 FastGPT 多文件工作流，同时处理 2 个分块，每块的表层与语法检查并行，最多 4 个模型请求；全部发现完成后，独立复核同时处理 2 批，最多 2 个请求。每次复核最多 5 条候选；超时、截断和输出格式异常有有界纠正及拆小恢复。文件队列逐份执行。

对图表、附件编号内的空格提供补充检查。重叠建议先缩小到实际改动范围，保留兼容的独立修改并合并重复修改；冲突、数字变化和无法定位的修改继续保护拒绝，记录原因。

## 从源码构建

Windows 10/11 64 位，Python 3.12、Node.js 24、Microsoft Edge WebView2 Runtime。

```powershell
python -m pip install -r requirements.txt
python build.py
```

公开仓库的核心引擎位于 engine/，桌面壳为 desktop.py、desktop-host.mjs，界面为 public/，启动更新检查为 update_client.py；版本和仓库地址集中在 release_info.py。构建产物在 dist/。修改版本、构建并将 ZIP 发布到对应版本的 GitHub Release 后，已安装的软件下次启动会发现新版。

图标使用用户提供图片右下角的直接裁切。第三方解析、PDF 字体和运行库许可证随引擎保留。
